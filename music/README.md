# Background music

Drop royalty-free audio tracks in this folder (`.mp3`, `.m4a`, `.aac`, `.wav`,
`.ogg`, `.flac`). They'll appear in the **Background music** picker in the UI,
and the chosen track is mixed under each vertical clip — automatically ducked
beneath speech.

You can also add tracks from the UI ("Add track").

> Use only music you have the rights to. Clip Maker does not provide or license
> any audio.
